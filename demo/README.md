# Демонстрация

Из корня репозитория после `uv sync --locked`:

```bash
uv run itg-llm-demo
uv run itg-llm-demo --scenario support
```

Ключ и доступ к API не нужны. Ответы этапов подготовлены вручную в
[scenarios.json](scenarios.json). Команда воспроизводит их через настоящий
pipeline: Pydantic-валидация, routing, ограничения, self-check, приоритеты,
трассировка и сборка JSON работают тем же кодом, что в реальном режиме.
Сами смысловой анализ, классификация и вердикт self-check в этом режиме
заранее записаны, а не вычисляются моделью.

| Имя | Что показать |
|---|---|
| `support` | Технические шаги, высокий приоритет и запрос недостающих данных |
| `complaint` | Эмпатичный ответ на задержку заказа |
| `sales` | Короткий ответ без выдуманной цены |
| `feedback` | Благодарность с упоминанием конкретного курьера |
| `question` | Практический ответ начинающему разработчику |

Полный пример выхода — [output.json](output.json), новый запуск пишет
в `results/demo.json`. Значения времени этапов могут отличаться.

Для реального анализа используйте основной CLI с ключом из `.env`:

```bash
uv run itg-llm --file examples/08_support.txt --output results/support_live.json
```

Чтобы показать устойчивость к сбоям без сети:

```bash
uv run pytest -q tests/test_guardrails.py tests/test_llm_client.py
```
